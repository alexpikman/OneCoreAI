# Project records

- [Current Work](CURRENT_WORK.md) — concise, replaceable snapshot of the latest confirmed state.
- [Development Plan](DEVELOPMENT_PLAN.md) — planned work and priority sequence; checked items still require implementation evidence.
- [Changelog](CHANGELOG.md) — completed milestones and durable historical record.

## Maintenance rules

- Keep `CURRENT_WORK.md` at 150 lines or fewer. It contains exactly seven sections: version/state, last confirmed milestone, implemented capabilities, unfinished work, known problems, latest verification, next recommended task.
- Move completed milestones and superseded detail from Current Work into Changelog in the same change that updates the snapshot.
- Do not copy raw chat history or secrets into project records.
- Keep future work in Development Plan; do not use it as a second status report.

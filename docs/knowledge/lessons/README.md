# Reviewed Lessons

Store concise, reusable lessons only after the procedure lifecycle review.

A lesson must identify:
- The recurring failure or successful pattern.
- Evidence and affected procedure IDs.
- The actionable prevention or verification rule.
- Scope and known exceptions.
- Review status and date.

Do not store raw chat transcripts, secrets, personal data, or unverified model speculation. Promote a lesson into an approved procedure when it changes repeatable execution behavior; otherwise keep it as supporting knowledge.

# Procedure Proposals

Store candidate procedure and role changes here before review.

Filename convention: `<stable-id>-v<major>.<minor>.<patch>.md`.

Each proposal must record:
- Candidate document ID and proposed version.
- Problem statement and evidence/source operation IDs.
- Proposed triggers, inputs, outputs, permissions, and acceptance tests.
- Architect review outcome.
- QA review outcome.
- Explicit owner approval or rejection.

Proposals are not active instructions. Runtime routing must ignore this directory.

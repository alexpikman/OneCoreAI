# OneCoreAI project reference

Автономный навигационный справочник по интерфейсу и исходникам проекта.

## Файлы
- `index.html` — единственная точка входа. Данные индекса встроены в HTML, поэтому браузер не должен загружать JSON через `fetch` и может открыть страницу напрямую.
- Справочник индексирует страницы `src/pages`, компоненты `src/components`, навигационные группы и все файлы Git-дерева на момент генерации.

## Открытие
Откройте `design/index.html` в браузере. Для Tailwind CSS используется CDN, поэтому для оформления требуется подключение к интернету. Сами данные справочника встроены в HTML.

## Актуализация
При изменении интерфейса или структуры репозитория обновить индекс:
1. Получить актуальное Git-дерево ветки `main`.
2. Сверить группы навигации с `src/data/appNavigation.ts`.
3. Сверить страницы с `src/App.tsx` и соответствующими файлами `src/pages/**`.
4. Сверить архитектурные связи с фактическими импортами и серверными модулями.
5. Пересобрать встроенный JSON в `index.html`; обновить дату генерации.
6. Проверить поиск, навигацию, ссылки GitHub и открытие файла через `file://`.

## Ограничения текущей версии
- Справочник является индексом и картой переходов, а не полным построчным описанием каждого компонента.
- Автоматическое извлечение props, состояния, API-контрактов и Tailwind-классов пока не реализовано.
- Описания без прямого анализа тела компонента помечены как навигационные; источник истины — исходный файл и документация в `docs/`.
